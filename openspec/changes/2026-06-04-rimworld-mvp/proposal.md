# Proposal: RimWorld MVP — Браузерный колонийный симулятор

## What

MVP браузерной игры в стиле RimWorld: изометрическая карта, 3 колониста, система потребностей, автономная job-система, базовое строительство, пауза.

## Why

Создать играбельный прототип колонийного симулятора, где персонажи живут самостоятельно — едят, спят, строят по приоритетам. Это проверяет ядро механик (job-система + потребности) на React + Canvas в браузере.

## Scope

### In scope
- Изометрическая карта 30×20 тайлов (32×16px каждый)
- 3 колониста с именами и цветными аватарами
- Потребности: голод и сон (падают со временем)
- Job-система: колонист сам выбирает задачу по приоритету (есть > спать > строить > перемещение)
- Еда (на земле) и кровати (строить) как сущности
- Строительство: стены и кровати (выбрать инструмент → кликнуть на карту)
- A* pathfinding для перемещения по карте
- Canvas 2D рендер (цветные прямоугольники, без спрайтов)
- Пауза + управление скоростью (остановить / 1x / 2x)
- HUD: полоски потребностей выбранного колониста, меню строительства
- Колонист ходит по клику правой кнопкой (команда)

### Out of scope
- Враги, бой, рейды
- Отношения между колонистами
- Травмы и медицина
- Фарм, охота, производство
- Электричество, трубы
- Спрайты и художественный контент
- Миникарта, туман войны
- Сохранение / загрузка

## Success criteria
- 3 колониста автономно существуют на карте: ходят, едят, спят
- Потребности падают, колонист реагирует (голоден → нашёл еду → пошёл есть)
- Игрок строит стены и кровати, колонист использует их
- Пауза работает мгновенно
- Управление: клик по колонисту → инфо, ПКМ → команда движения
- Карта прокручивается камерой
